# UVCS MCP 1.2.1

UVCS MCP 1.2.1 is a production patch release for dependable guarded multi-workspace operation with real Plastic SCM workspaces.

## Fixed

- Guarded repository identity parsing now correctly removes Plastic status suffixes such as `(cs:… - head)` and `(head:…)`. Valid workspaces with local pending changes no longer fail repository allowlist checks.
- JSONL audit logs now create their parent directories automatically, making per-workspace audit paths in fleet manifests work without manual preparation.
- Cursor MCP configuration directories are kept local and excluded from source control.

## Live fleet validation

- Validated four guarded, repository-pinned Plastic SCM workspaces through `uvcs-mcp doctor --manifest=...`.
- Created a test branch independently in all four workspaces through the MCP prepare/confirm workflow.
- Confirmed each target requires its own explicit workspace selector and has separate audit logging.

## Quality gate

- 70 automated tests passing.
- ESLint and Node syntax validation passing.

## Upgrade

```bash
npx -y @proanima/uvcs-mcp@1.2.1 init --client=cursor,codex --manifest=workspaces.json
npx -y @proanima/uvcs-mcp@1.2.1 doctor --manifest=workspaces.json
```

Restart the MCP client after upgrading. See the [multi-workspace guide](../multi-workspace.md), [security model](../security.md), and [production-readiness checklist](../production-readiness.md).
